# Etalk Spoken English

A responsive single-page website for Etalk Spoken English, an English-language and communication training institution in Domkal, Murshidabad, West Bengal.

## Run locally

This is a dependency-free static site. Open `index.html` in a browser, or serve this folder with any static HTTP server. No build step is required.

## Customize

- Update the gallery placeholders in `index.html` with authentic Etalk photos or videos when available.
- The enquiry form validates the visitor's details in the browser and opens WhatsApp with a prefilled message to the supplied primary phone number. The site does not store form submissions.
- Course information, contact details, metadata, and the Google Maps search link are maintained directly in `index.html`.

The hero and about images are illustrative stock photography, not photos of Etalk students.
